# 天气查询输出模板

## 标准输出格式

每次天气查询必须严格按照以下格式返回，不得增删字段、不得改变字段顺序：

```
消息来源：源源编写的天气Skills返回
城市：{city}
当前温度：{temp_C}°C
天气状况：{weatherDesc}
湿度：{humidity}%
```

## 字段说明

| 占位符          | 数据来源（wttr.in JSON 路径）                        | 示例值  |
| --------------- | ---------------------------------------------------- | ------- |
| `{city}`        | 从用户输入提取的城市名                               | 北京    |
| `{temp_C}`      | `current_condition[0].temp_C`                        | 18      |
| `{weatherDesc}` | `current_condition[0].weatherDesc[0].value`          | 多云    |
| `{humidity}`    | `current_condition[0].humidity`                      | 65      |

## 示例输出

```
消息来源：源源编写的天气Skills返回
城市：北京
当前温度：18°C
天气状况：多云
湿度：65%
```

## 注意事项

- `{temp_C}` 只保留整数部分，无需小数位。
- `{weatherDesc}` 使用 wttr.in 返回的中文描述原文，不做额外翻译。
- `{humidity}` 只保留数字，`%` 号由模板固定提供。
- 除以上五行外，**不要**在输出中添加任何额外说明、换行或装饰字符。
